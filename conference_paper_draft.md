## Abstract
Surface electromyography (sEMG) offers an intuitive, non-invasive neuromuscular modality for human-machine interaction (HMI) and robotic teleoperation. While multi-channel high-density arrays provide high recognition fidelity, their physical bulk, complex skin preparation, and hardware cost limit widespread wearable adoption. This paper presents a preliminary feasibility investigation into single-channel sEMG hand gesture recognition evaluated across a pilot cohort of human subjects performing five fundamental gestures (Fist, Open Palm, Pinch, Wrist Up, and Wrist Down). Raw bio-potentials acquired at 1,000 Hz via a single differential bipolar montage are conditioned through a sequential 50 Hz notch filter and a 20–450 Hz bandpass filter. Four classical time-domain features—Mean Absolute Value (MAV), Root Mean Square (RMS), Waveform Length (WL), and Zero Crossings (ZC)—are extracted from segmented contraction windows. Baseline classification using Support Vector Machines (SVM) and K-Nearest Neighbors (KNN) demonstrates that single-channel configurations can achieve promising preliminary recognition accuracies of up to $65.4\%$, establishing a viable baseline for lightweight assistive controllers.

**Keywords**: Surface Electromyography (sEMG), Hand Gesture Recognition, Single-Channel Interface, Time-Domain Features, Support Vector Machine (SVM).

---

## 1. Introduction
Human-Machine Interfaces (HMIs) driven by physiological bio-potentials have gained significant interest across robotic prosthetics, virtual reality navigation, and assistive communication aids. Surface electromyography (sEMG) non-invasively captures the electrical activity generated by voluntary skeletal muscle contractions, reflecting user motor intent.

Traditional myoelectric interfaces predominantly rely on multi-channel electrode arrays (e.g., 8-channel armbands or 64–128 channel high-density grids). While multi-channel configurations capture spatial muscular activation topologies, they introduce substantial practical drawbacks for daily wearable deployment:
- High component count and power consumption.
- Cumbersome electrode placement and calibration friction.
- Elevated computational overhead.

Single-channel sEMG interfaces represent an attractive, ultra-compact alternative. However, capturing distinct gesture patterns using a single differential electrode pair poses significant signal processing challenges, particularly spatial crosstalk and muscle co-contraction interference. 

This paper investigates the preliminary feasibility of classifying five distinct hand gestures using a single differential sEMG channel, evaluating classical time-domain feature representations and baseline supervised learning models on a pilot dataset.

## 2. Experimental Setup and Pilot Data Acquisition

### 2.1 Hardware and Electrode Configuration
- **Acquisition Hardware**: National Instruments Data Acquisition (NI-DAQ) system (`Dev1/ai0`).
- **Electrode Montage**: Single differential bipolar montage consisting of two Ag/AgCl surface electrodes placed over the forearm flexor muscle belly (Flexor Carpi Radialis) with an inter-electrode distance of 20 mm, coupled with a reference/ground electrode on a neutral bony landmark (elbow/wrist).
- **Sampling Frequency**: $f_s = 1,000\,\text{Hz}$.
- **Input Voltage Range**: $\pm 5.0\,\text{V}$.

### 2.2 Pilot Recording Protocol
Data was collected from a pilot cohort of 2 healthy adult subjects under a controlled trial protocol:
1. **Target Gestures (5 Classes)**:
   - **Fist**: Closed hand contraction.
   - **Open Palm**: Extension of all five digits.
   - **Pinch**: Isometric pinch between thumb and index finger.
   - **Wrist Up**: Upward wrist extension.
   - **Wrist Down**: Downward wrist flexion.
2. **Cycle Timing**: Each trial consisted of a 4-second active muscle contraction followed by a 4-second complete rest period.
3. **Dataset Volume**: Subjects performed 30 repetitions per gesture, yielding a pilot dataset of 300 total gesture trials.

## 3. Signal Conditioning and Feature Extraction

```
[ Raw sEMG Input (1000 Hz) ]
             │
             ▼
  [ 50 Hz Notch Filter (Q=30) ]
             │
             ▼
[ 20–450 Hz 4th-Order Bandpass ]
             │
             ▼
 [ 1.5s Contraction Windowing ]
             │
             ▼
[ 4 Time-Domain Features: MAV, RMS, WL, ZC ]
```

### 3.1 Digital Filtering
Raw sEMG signals are susceptible to powerline interference and low-frequency motion artifacts. The signal conditioning pipeline applies:
1. **Harmonic Notch Filter**: A 2nd-order IIR notch filter centered at $f_0 = 50\,\text{Hz}$ with a quality factor of $Q=30$ to eliminate AC mains hum.
2. **Bandpass Filter**: A 4th-order Butterworth bandpass filter with cutoff frequencies at $20\,\text{Hz}$ and $450\,\text{Hz}$ to eliminate baseline drift and high-frequency noise.

### 3.2 Feature Extraction
From each segmented 1.5-second ($N=1,500$ samples) contraction window, four classical time-domain features are extracted:

1. **Mean Absolute Value (MAV)**:
   $$\text{MAV} = \frac{1}{N} \sum_{i=1}^{N} |x_i|$$
2. **Root Mean Square (RMS)**:
   $$\text{RMS} = \sqrt{\frac{1}{N} \sum_{i=1}^{N} x_i^2}$$
3. **Waveform Length (WL)**:
   $$\text{WL} = \sum_{i=1}^{N-1} |x_{i+1} - x_i|$$
4. **Zero Crossings (ZC)**:
   $$\text{ZC} = \sum_{i=1}^{N-1} \mathbb{I}\left( (x_i \cdot x_{i+1} < 0) \land (|x_i - x_{i+1}| \ge \epsilon) \right)$$
   *(where $\epsilon = 0.005\,\text{V}$ is a noise threshold).*

## 4. Machine Learning Classification
To establish a clear performance baseline, two standard supervised classifiers were trained:
1. **Support Vector Machine (SVM)**: Configured with a Radial Basis Function (RBF) kernel ($C=10.0, \gamma=\text{'scale'}$).
2. **K-Nearest Neighbors (KNN)**: Configured with Euclidean distance metric and $k=5$ neighbors.

**Evaluation Protocol**: The pilot dataset was partitioned using an $80\% / 20\%$ stratified train/test split. Feature normalization was performed using standard z-score scaling across the feature vectors.

---

## 5. Preliminary Results and Discussion

### 5.1 Classification Accuracy Comparison
Table 1 summarizes the preliminary classification performance of the baseline models on the pilot dataset.

| Model Architecture | Training Accuracy (%) | Testing Accuracy (%) | Inference Latency (ms) |
|---|---|---|---|
| K-Nearest Neighbors ($k=5$) | 74.2% | 61.8% | 12.4 ms |
| **Support Vector Machine (RBF)** | **79.5%** | **65.4%** | **0.25 ms** |

### 5.2 Observations
- **Feasibility**: Both models significantly exceeded the 20.0% chance-level threshold for 5-class gesture classification, confirming that a single differential channel contains adequate neuromuscular information for coarse gesture separation.
- **Latency**: The SVM model demonstrated near-instantaneous inference ($0.25\,\text{ms}$), well within the $100\,\text{ms}$ threshold required for real-time robotic or prosthetic control.
- **Limitations**: The primary classification confusions occurred between *Wrist Up* and *Wrist Down*, where overlapping amplitude envelopes on a single flexor channel produce similar time-domain features.

---

## 6. Conclusion and Future Work
This paper presented a preliminary pilot feasibility study for single-channel sEMG hand gesture classification across five gesture classes. Using a basic two-stage filtering pipeline and four time-domain features, the SVM model achieved a testing accuracy of $65.4\%$ with ultra-low inference latency ($0.25\,\text{ms}$).

### Explicit Future Scope:
To elevate this preliminary study toward robust, real-world deployment, future work will focus on:
1. **Cohort Expansion**: Validating the pipeline across a diverse population cohort ($N \ge 15$ subjects) across different age groups and genders.
2. **Multi-Domain Feature Engineering**: Integrating non-linear complexity metrics (Hjorth parameters) and frequency-domain representations (Spectral Entropy).
3. **Adaptive Standardization**: Developing subject-specific calibration algorithms to mitigate inter-individual physiological impedance variations.
4. **Assistive Speech Synthesis**: Deploying an end-to-end, real-time Sign-to-Speech translation interface for assistive vocal communication.
